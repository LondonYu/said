## 读取与界面约定

| 用户行为 | 结果与边界 |
| --- | --- |
| 首次进入首页 | 无需钱包，首次挂载读取board第一页。应用已有余额/钱包网络检查不能阻塞公共流，也不能把其成功等同于历史成功。壳先渲染，列表显示真实加载状态 |
| “我的留言”未连接 | 显示连接引导，不查作者历史，不冒充空历史；不自动弹钱包或请求签名 |
| “我的留言”已连接 | 按当前完整公钥独立查询author范围；不能筛首页代替历史，不依赖曾加载过首页 |
| 加载更多 | 单次取一页、显式点击；按当前nextCursor继续。整页被过滤但sourceExhausted=false仍可继续，不能显示“全部读完” |
| 刷新 | 新请求从最新页开始；使旧请求失效，成功后重置分页边界。刷新失败保留同一范围原有记录并标明未更新成功，不伪造空历史 |
| 单笔暂不可读/失败 | 展示已验证消息及“部分记录暂不可读”与显式重试，保存unavailable签名；不是无留言，也不是该作者删帖 |
| 操作级失败 | 初次加载显示失败与重试；加载更多/刷新失败保留既有内容及原游标，允许重试该操作，不把游标提前推进 |
| 真空页 | 仅在可用候选范围扫描结束、无消息且无待解决签名时用“暂未发现留言”等克制文案；不是“从未发布过”的全链保证 |

复用createHistoryClient的默认页大小、并发与超时，不另写RPC取数据。只在进入范围、点击刷新/加载更多/重试时请求；不自动滚动翻页、不后台轮询、不输入逐字请求，不递归凑满一屏有效消息。开发StrictMode的清理请求必须失效，不以取消StrictMode掩盖生命周期问题。

## 生命周期、分页合并与重试

1. 公共board与author:<完整公钥>具有独立状态。切换范围或账户时同步隔离旧内容、旧详情/错误及loading，取消旧请求；不能等useEffect下一帧才隐藏旧作者历史。可用key重建或显式归属守卫，保持钱包余额既有隔离。
2. 每个范围一次只允许一个历史操作；用同步请求锁/序号防同一事件周期连点，不能只依赖异步setState。每次请求捕获query key、generation与原游标；取消、离开、刷新、卸载后旧结果/错误/finally不得覆盖或解锁新操作。迟到provider结果也要回归测试。
3. 离开范围可中止并在下次进入重新读取第一页；不要求持久缓存。主题/语言切换、弹出详情与搜索、在首页连接/切换钱包均不能无意义地重查公共历史。
4. 合并按signature去重，不按正文/作者/slot；保持RPC页面顺序，同slot不按blockTime捏造精确交易先后。保存已请求边界，除模块自身before无进展外，还防跨页A→B→A的游标循环，明确停止并允许刷新；不能无声无限重复加载。
5. unavailable队列与内容、分页状态分开，按签名去重、归属于查询范围；翻页不能抹掉前页未解决签名。相同范围成功刷新也须保留尚未解决项，明确重试/解析无效后才移除，换账户则隔离清空。scanned为本次去重候选数，不当成全链留言总数或全站编号。
6. 用户显式重试调用retrySignatures，每次最多20个唯一签名，其余保留下一次。返回message的签名从队列移除并合并至内容；仍unavailable保留；本批明确无效的候选可移除。重试失败保留整批队列，不能丢数据。
7. 重试结果的nextCursor=null/sourceExhausted=false不是分页结果，不能覆盖原列表cursor/结束标记。恢复消息按slot从新到旧插入，已显示同slot条目的相对顺序稳定，不声称精确块内顺序。分页源已结束但仍有unavailable时，仍提供重试，不展示无条件的“已读完全部历史”。

## 内容、详情与搜索

- 卡片沿用当前布局，真实公钥可截断，详情显示完整公钥/正文/交易签名/slot/实际网络费。身份来自GuestbookMessage.author，不造昵称、“认证用户”、编号或总数；slot字段标slot而非区块高度。
- blockTime按现有语言格式化，null显示“时间未知”；不得以当前时间/epoch/估算时间填补。费用精确显示实际lamports或安全格式化SOL，标明Devnet，不能硬编码5000。
- 正文只作React文本节点渲染，保留换行与原始文本。HTML、Markdown、javascript:等不能变成可执行内容，不使用dangerouslySetInnerHTML或自动可点击正文链接。
- 详情Explorer链接只从已校验signature构造到固定官方域名，始终带cluster=devnet；新窗口带noopener/noreferrer。打开详情复用内存已验证记录，不额外重扫链；返回到原首页/我的/搜索上下文。
- 当前PreviewFeed/Search/Detail样例不得混入真实用户路径或作为RPC失败兜底；可保留作为测试样例。PreviewEditor及“本地预览/未签名/未上链”模拟流程保持原语义，不新增发布或签名按钮。
- 搜索仅过滤**当前范围已加载的真实记录**（正文与作者公钥），明确标注范围，不宣传全链搜索，不请求额外RPC。输入搜索、开详情、返回不能抹掉分页和未解决签名；未连接的“我的”不搜索其他账户残留数据。切账户时关闭/隔离旧个人详情及搜索内容。

## 语言、响应式与验收

新增状态文案覆盖简中/繁中/英文，沿用现有主题/字体/透明Logo；不用新的标语或营销文案。错误的通用标题本地化，RPC原文可放错误详情中纯文本显示。保留44×44触控目标、输入字号至少16px、长公钥与正文换行、安全区和键盘逻辑。
